# Changelog

This file is a short, manually updated history of each released version.

## Unreleased

- Split the application into focused modules without changing its saved data or terminal workflow.

## 1.0.0 - 2026-08-03

- Added importing for the tested Apple Card, Amex, Chase credit, Chase checking, and Discover CSV layouts.
- Added duplicate-file detection and overlapping-transaction merging.
- Added account-scoped exact and text-pattern categorization rules.
- Added transaction splitting, person assignment, named group categories, refunds, income, and reimbursements.
- Added yearly JSON state files and interruption-safe saves.
- Added monthly Excel dashboards, HTML reports, category audit detail, person cards, dated bill detail, and a normalized transaction ledger.
- Added configurable incoming-checking treatment and public extension documentation.
